
# نظام جوهرة فلسطين

## طريقة التشغيل

### تشغيل الواجهة الأمامية

```bash
cd frontend
npm install
npm run dev
```

### تشغيل السيرفر الخلفي

```bash
cd backend
npm install
npm run dev
```

---

## المميزات الحالية

- واجهة عربية
- وضع ليلي
- لوحة تحكم أولية
- API للمنتجات
- نظام ويب للموبايل والكمبيوتر

---

## التقنيات المستخدمة

- React
- Vite
